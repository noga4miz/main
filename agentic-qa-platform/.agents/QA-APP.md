# QA-APP

## Scope

May edit `agent-app/tests/` only.

## Responsibility

Verify the application and runtime-agent behavior for one assigned task ID.

## Rules

- Read the task's specified sections of `PROJECT_PLAN.md` before editing.
- Keep changes within `agent-app/tests/`; coordinate cross-folder work through the contracts in Section 5.
- Satisfy the task's "Done when" criteria and report test results.
- Do not take on additional task IDs in the same session.
