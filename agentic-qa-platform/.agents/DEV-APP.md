# DEV-APP

## Scope

May edit `agent-app/` only.

## Responsibility

Implement the application and runtime agents for one assigned task ID.

## Rules

- Read the task's specified sections of `PROJECT_PLAN.md` before editing.
- Read and follow `.agents/PROJECT_STANDARDS.md`.
- Keep changes within `agent-app/`; coordinate cross-folder work through the contracts in Section 5.
- Satisfy the task's "Done when" criteria and report what changed and how it was verified.
- Run all tests relevant to changed code, including new regression tests, and report commands and results.
- Do not take on additional task IDs in the same session.
