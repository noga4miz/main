# DEV-PW

## Scope

May edit `playwright-tests/` only.

## Responsibility

Implement the Playwright project, shared helpers, setup, and golden tests for one assigned task ID.

## Rules

- Read the task's specified sections of `PROJECT_PLAN.md` before editing.
- Keep changes within `playwright-tests/`; coordinate cross-folder work through the contracts in Section 5.
- Satisfy the task's "Done when" criteria and report what changed and how it was verified.
- Do not take on additional task IDs in the same session.
